Junker der Provinz on Flatpak

Hi there! This is where my desktop apps live as Flatpaks. Add the repository once, and every new version reaches you through flatpak update or your software center, just like the rest of your apps.

Add the repository

flatpak remote-add --user --if-not-exists junkerderprovinz @BASE_URL@/junkerderprovinz.flatpakrepo

The apps run on the GNOME runtime from Flathub. Most systems have Flathub already. If yours doesn't, add it first:

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Install an app

Copy the command, or click Install and your software center takes it from there. The button sets up both repositories for you, so it works without the commands above.

Updates

Run flatpak update whenever you like, or let your software center do it for you. If a new version gives you trouble, the one before it is still here, and flatpak remote-info --log junkerderprovinz <app ID> shows the commit to go back to with flatpak update --commit=<commit> <app ID>.
